Revised step-by-step: BGR color-based masking with matplotlib
Step 1: Read a sample frame from your video
What you're doing:
Read one frame from your video to inspect
This gives you a frame to work with for exploration

Thought process:
You need a representative frame to sample from
Pick a frame that shows the field clearly (good lighting, visible field area)
This frame will be your reference for finding BGR values

Questions to consider:
Which frame should you use? (Early in video? Middle? One with good field visibility?)
How do you read just one frame instead of processing the whole video?


Step 2: Display the frame with matplotlib
What you're doing:
Convert frame from BGR to RGB (matplotlib uses RGB)
Display the frame using matplotlib
This lets you see the frame and visually inspect it

Thought process:
Matplotlib displays in RGB, but your frame is BGR
Need to convert for correct color display
Displaying helps you see where to sample
You can see the field area visually
Why convert BGR to RGB:
OpenCV uses BGR order
Matplotlib uses RGB order
Converting ensures colors display correctly
But remember: original frame still has BGR values!


Step 3: Use matplotlib to inspect pixel values
What you're doing:
Use matplotlib's interactive features to see pixel coordinates
Hover over pixels or use data cursor to see values
Identify good field green areas visually

Thought process:
Matplotlib can show coordinates as you move mouse
Or you can click to get coordinates
Visually identify "good field green" areas
Avoid shadows, lines, or worn patches
Pick representative field areas

Questions to consider:
How do you get pixel coordinates from matplotlib?
Can you click to sample, or do you need to note coordinates?
What areas look like "good field green"?


Step 4: Access BGR values from original frame
What you're doing:
Use the coordinates you identified (from matplotlib inspection)
Access the pixel in the original BGR frame (not the RGB display version)
Get the actual BGR values at that pixel

Thought process:
Matplotlib helped you find good coordinates
But you need BGR values from original frame (not RGB display)
Access pixel using those coordinates
Get [B, G, R] values

Important:
Display version is RGB (for visualization)
Original frame is BGR (what you need for masking)
Sample from original frame, not displayed version


Step 5: Sample multiple field areas
What you're doing:
Sample several pixels from different field areas
Get BGR values for each
This helps you understand the range of "field green"

Thought process:
Field might have slight color variations
Sample from: bright areas, slightly darker areas, different parts of field
See what range of BGR values field green covers
This helps you define your range later

Questions to consider:
How many samples should you take?
Should you sample from shadows too?
What's the variation in field green?


Step 6: Analyze the BGR values to define your range
What you're doing:
Look at all your sampled BGR values
Find the minimum and maximum for each channel (B, G, R)
Define your color range based on these samples

Thought process:
You have multiple BGR samples: (B1, G1, R1), (B2, G2, R2), etc.
Find: min Blue, max Blue, min Green, max Green, min Red, max Red
This creates a range that captures your field green variations
Might need to adjust range (wider for more variation, narrower for precision)

Considerations:
Too narrow: might miss some field areas
Too wide: might include non-field areas (green ads, etc.)
Balance based on your samples


Step 7: Create an empty mask
What you're doing:
Create a black image the same size as your frame
This will become your mask

Thought process:
Same as before - need empty canvas
Same dimensions as frame
Will fill with white where field is detected


Step 8: Find pixels within your BGR range
What you're doing:
Check each pixel in frame against your defined BGR range
Identify which pixels are "field green"

Thought process:
Use the range you defined from matplotlib samples
Check: Is Blue in range? AND Green in range? AND Red in range?
If all three match → pixel is field green
This identifies field pixels across the entire frame


Step 9: Set mask pixels to white where field is found
What you're doing:
For pixels identified as field green → set mask to white
For other pixels → keep mask black

Thought process:
Same as before
White = keep (field area)
Black = mask out (background)


Step 10: Optional: clean up the mask
What you're doing:
Remove noise, smooth edges, fill holes

Thought process:
Same as before - make mask cleaner


Step 11: Apply mask to your frame
What you're doing:
Combine mask with original frame
Result: frame with only field area visible

Thought process:
Same as before - filter frame using mask


Key differences with matplotlib approach

Sample multiple areas to understand variation
Define range based on actual samples

Advantages:

Better understanding of field color variation
More informed range definition
